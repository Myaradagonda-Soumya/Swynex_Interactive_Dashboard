# SWYNEX Interactive Employee Analytics Dashboard

## 📊 Project Overview

This project was developed as part of my **SWYNEX Technologies Internship – Task 3: Interactive Dashboard**.

The objective of this project is to transform employee data into an interactive and easy-to-understand dashboard using **Microsoft Power BI**.

The dashboard provides a clear overview of employee distribution, salary, age, performance, remote work, regions, departments, and joining trends.

---

## 🎯 Objectives

- Create an interactive employee analytics dashboard.
- Present important employee KPIs.
- Analyze employee distribution across departments and regions.
- Analyze salary and age-related information.
- Understand employee performance distribution.
- Analyze remote and non-remote employees.
- Identify employee joining trends over the years.
- Provide interactive filters for better data exploration.

---

## 📈 Dashboard Visualizations

The dashboard contains the following visualizations:

### Employees by Region
Shows the number of employees across different regions.

### Employees by Department
Shows employee distribution across departments using a treemap.

### Remote Work Distribution
Shows the distribution of remote and non-remote employees.

### Employee Performance Distribution
Shows the number of employees based on performance scores.

### Employees by Joining Year
Shows employee joining trends across different years.

### Average Salary by Department
Compares average salary across departments.

### Average Salary by Performance Score
Shows the relationship between performance levels and average salary.
